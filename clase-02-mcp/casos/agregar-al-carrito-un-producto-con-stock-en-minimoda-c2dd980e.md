# Agregar al carrito un producto con stock en MiniModa

- **Requisito:** Como cliente, puedo agregar al carrito un producto disponible para comprarlo y verificar que el carrito refleje correctamente el producto y su cantidad.
- **Prioridad:** media

## Datos

Producto: producto publicado con stock disponible (por ejemplo, Remera básica). Variante: talle y color válidos, si aplica. Cantidad: 1. Carrito inicialmente vacío.

## Pasos

1. Ingresar a MiniModa y abrir el catálogo de productos.
2. Seleccionar un producto que figure como disponible y con stock mayor a cero.
3. Elegir una variante requerida, como talle o color, si corresponde.
4. Indicar una cantidad igual a 1 y seleccionar «Agregar al carrito».
5. Abrir el carrito y revisar el producto agregado.

## Resultado esperado

El producto se agrega correctamente al carrito. El carrito muestra el nombre y la variante elegida, cantidad 1 y precio correspondiente; el contador del carrito aumenta y el subtotal coincide con el precio del producto. El stock disponible no se muestra como agotado.
