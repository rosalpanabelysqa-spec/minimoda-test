# Agregar al carrito un producto con stock en MiniModa

- **ID:** CP-01

- **Requisito:** Como cliente, puedo agregar al carrito un producto disponible para comprarlo y verificar que el carrito refleje correctamente el producto y su cantidad.
- **Prioridad:** media

## Precondiciones

- El carrito está vacío.
- El producto está publicado y tiene stock disponible.

## Datos

Producto: Body Manga Larga Estrellitas. Color: azul. Talle: 6M. Cantidad: 1. Precio: $8.500.

## Pasos

1. Ingresar a MiniModa y abrir el catálogo de productos.
2. Seleccionar el producto Body Manga Larga Estrellitas.
3. Elegir el color azul y el talle 6M.
4. Indicar una cantidad igual a 1 y seleccionar «Agregar al carrito».
5. Abrir el carrito y revisar el producto agregado.

## Resultado esperado

El carrito muestra el producto Body Manga Larga Estrellitas y la variante correcta (color azul, talle 6M), cantidad 1, precio $8.500 y total esperado $8.500. El contador del carrito aumenta. El stock disponible no se muestra como agotado.
